SportoStream

Duet Project

Sports Streaming Overlay & Real-Time Scoring System for Cricket, Football, Volleyball, and Table Tennis

Watch Stream on YouTube

SportoStream is a custom-developed sports streaming and real-time scoring system software designed to broadcast multi-sport matches (Cricket, Football, Volleyball, Table Tennis) with transparent, broadcast-quality graphics overlays and live web synchronization.

The Backstory

Last term, while chatting in class, my classmate Sajal Mondal suggested we build our own software to stream our team's cricket matches. Since I had experience with the Qt framework, I told him I'd look into it.

In November 2025, right in the middle of our term finals, the idea suddenly clicked. After some research and prototyping, I realized: We can actually do this. I immediately texted Sajal, and we agreed to build it together in December.

Despite a tight deadline and a setback when Sajal was injured by a cricket ball, we pushed through. Even while recovering, Sajal made an incredible contribution — without him, completing this would have been much tougher.

We are proud to announce that we now have our own dedicated software for our sports streaming!

Team Members & Roles

  • Kazi Rifat Morshed: System architecture, database design, class design, overlay server & database manager implementation, and Qt UI development.
  • Sajal Mondal: Co-developer, testing, and streaming coordination.

Technologies Used

C++ Qt Framework SQLite Web Technologies OBS Overlay Server

Key Features

  • Sports streaming overlay & real-time scoring system for Cricket, Football, Volleyball, and Table Tennis matches.
  • Custom overlay server delivering transparent graphic overlays directly to broadcasting software like OBS Studio.
  • Real-time scoring update engine synchronizing match data with a remote web server for live public scoreboards (akin to Cricbuzz).
  • Local SQLite persistence ensuring match logs and score histories are saved with low latency.
