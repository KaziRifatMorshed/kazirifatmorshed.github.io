SmartXm

Under Development · Group Project

Cross-Platform Anti-Cheat Exam Management & Judging System for Isolated Networks

SmartXm desktop application interface featuring exam management, local server integration, and evaluation pipeline

SmartXm is a cross-platform desktop application architected for conducting secure university laboratory examinations in isolated or local computer networks. The system integrates robust client-server communication, sandboxed code execution, and an offline auto-judging engine to establish a reliable, cheating-resistant exam delivery, submission, and automated evaluation workflow.

Key Technical Contributions

  • Network Architecture: Architected and implemented local and remote server networking, including native socket communication (Winsock2 / POSIX sockets) specifically engineered for network-isolated lab environments.
  • Integrated Student & Teacher UI: Designed and implemented modern Qt user interfaces featuring an embedded in-app PDF exam question viewer, built-in code editor/IDE, and instant submission system.
  • Concurrency & Data Persistence: Engineered multi-threaded networking pipelines and persistent database adapters utilizing Qt 6 modules (Core, Widgets, Network, Sql, Concurrent, PDFWidgets) across MySQL/MariaDB and SQLite backends.
  • Auto-Judging Pipeline: Contributed to the offline evaluation mechanism for compile-and-run verification against test suites in isolated sandbox sessions.

Technologies & Tools

C++ Qt 6 Framework QMake / Ninja MySQL / MariaDB SQLite Native Sockets qScintilla2
