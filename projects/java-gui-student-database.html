JAVA GUI: Student-Person Database

Group Project

Object-Oriented Record Management System Desktop Application

An Object-Oriented desktop application engineered in Java using the Java Swing GUI toolkit to manage and manipulate student-person profiles, records, and academic information.

Key Features & Architecture

  • Object-Oriented Design: Strict adherence to OOP principles (inheritance, encapsulation, polymorphism, abstraction) for extensible domain modeling of persons and students.
  • Persistent Storage: Implemented robust data persistence via native Java object serialization and deserialization for reliable save and load operations.
  • Interactive Swing GUI: Comprehensive graphical components for searching, sorting, updating, and filtering student entries.

Technologies Used

Java Java Swing Object-Oriented Programming (OOP) Java Serialization
