KU-Class-Routine-Generator

Group Project

Automated Class Routine Generation System for Khulna University with Credit-Based Scheduling

Intelligent Academic Scheduling

Multi-constraint satisfaction and optimization for university routines

KU-Class-Routine-Generator is an automated schedule generation software engineered to resolve complex university timetabling challenges. Designed tailored to the academic credit structure and resource allocations of Khulna University, the system automates slot mapping while preventing instructor conflicts, class batch overlaps, and venue constraints.

Key Responsibilities & Contributions

  • PySide6 Graphical Interface: Designed and implemented an intuitive, responsive graphical user interface in PySide6 to handle batch inputs, course data, room lists, and teacher preferences.
  • Core Scheduling Algorithms: Contributed algorithmic routines to efficiently resolve conflicting class assignments and time slots, maximizing room utilization across university departments.
  • Constraint Verification & Testing: Conducted stress testing and verification to ensure algorithm correctness, edge-case handling, and deterministic output under heavy constraint scenarios.

Technologies Used

Python PySide6 C++ Scheduling Algorithms
